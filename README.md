# 3분만

담배 생각이 나는 **그 3분**을 넘기게 돕는 금연 웹앱.

담배 생각은 대개 3~5분이면 지나갑니다. 그 짧은 순간을 못 넘겨서 금연이 무너집니다. 3분만은 그 순간 하나에 집중합니다.

## 어떻게 돕나요

**단칼 금연입니다.** 줄여나가는 기능은 없습니다. 조금씩 줄이는 것보다 한 번에 끊는 쪽이 성공률이 높다는 연구(Lindson-Hawley et al., 2016)를 따랐습니다.

**SOS.** 담배 생각이 나면 어느 화면에서든 버튼 하나를 누릅니다. 3분 타이머와 호흡 가이드가 시작되고, 직접 등록해 둔 사진과 끊는 이유가 화면을 채웁니다. 3분이 지나면 욕구가 지나갔는지 기록합니다.

**금단 타임라인.** 20분 뒤 심박수, 48시간 뒤 미각과 후각, 72시간의 고비까지 — 지금 몸에서 무슨 일이 일어나는지 보여줍니다. 참는 시간이 아니라 회복하는 시간이 됩니다.

**고비 예보.** 주로 담배를 피우던 시간대를 미리 등록해 두면, 그 시간이 오기 전에 앱이 먼저 말을 겁니다.

**감정 기록.** 감정 휠로 기분과 욕구 강도를 남기면, 어떤 감정일 때 담배가 당기는지 그래프로 드러납니다.

**재발해도 리셋하지 않습니다.** 한 대 피웠다고 D-day가 0이 되지 않습니다. "한 대 피웠으니 끝났다"는 마음이 완전한 재발을 부르기 때문입니다. 흔들린 날도 여정의 일부로 남습니다.

## 쓰는 법

브라우저로 열고 홈 화면에 추가하면 앱처럼 씁니다. 설치가 필요 없고, 기록은 전부 **본인 기기에만** 저장됩니다. 서버로 전송되는 데이터가 없습니다.
